# 技术支持处理规范

## 核心规则

- 先确认问题现象、发生时间、软件版本和影响范围。
- 有错误码时必须在回复中保留错误码。
- 排查顺序应从低风险操作开始。
- 不得直接断定没有证据支持的故障原因。
- 不得要求用户提供密码、验证码、密钥或完整隐私信息。
- 涉及生产故障、数据丢失或大面积异常时，应建议升级人工技术支持。
